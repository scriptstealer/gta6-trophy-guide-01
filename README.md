An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy with its official name, description, and grade, a guide in my own words with cited sources, a platinum roadmap, missable flags, and a checklist that saves in your browser — with filters, search, a spoiler setting, and export/import. Works with the network off, no Rockstar artwork.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
